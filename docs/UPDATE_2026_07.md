# Project Restructuring and Bug Fixes

## Overview
This document outlines the recent restructuring of the project to isolate the web dashboard and fix module resolution issues.

## Changes Made
1. **Module Resolution Fix**: Addressed the `ERR_MODULE_NOT_FOUND` error for `express` by adding a `postinstall` script to the root `package.json`. This ensures that `npm install --prefix dashboard` is automatically executed when dependencies are installed at the root level.
2. **AI Feature Removal**: Completely removed the Gemini AI integration and chat components from both the frontend (`App.tsx`) and the backend (`server.js`) to adhere strictly to the non-simulation constraints.
3. **Directory Cleanup**: Consolidated all documentation, images, and backup archives into the `/docs` directory to maintain a clean project root.

## Current Architecture
- `/dashboard`: Contains the web interface (React/Vite) and backend server (Node.js/Express).
- `/godhand`: Contains the core Minecraft Mod source code (Java/Fabric).
- `/docs`: Contains all project documentation, backups, and reference materials.
